# ✏️ 在线电子黑板

## 🚀 项目简介

一个基于 HTML5 Canvas 的在线绘图工具，支持画笔、橡皮、自定义颜色粗细、撤销和 PNG 导出，适合在线书写、标注和简单绘图场景。

## ⭐ 核心亮点

- **画笔 + 橡皮**：一键切换，橡皮自动放大擦除范围
- **自定义颜色**：原生取色器，任意颜色选择
- **可调粗细**：1-20px 滑块调节笔刷粗细
- **撤销功能**：支持单步撤销（Ctrl+Z 快捷键）
- **PNG 导出**：一键导出画布内容为 PNG 图片
- **高 DPI 适配**：Retina 屏幕清晰渲染

## 🛠️ 技术栈

- HTML5 Canvas API
- Pointer Events（支持鼠标 + 触控笔）
- 原生 JavaScript，无框架依赖

## 🚀 使用方式

直接用浏览器打开 `index.html`，或部署到 GitHub Pages：

```bash
open index.html
```
