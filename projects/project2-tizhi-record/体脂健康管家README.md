# 💪 体脂健康管家

## 🚀 项目简介

基于扣子(Coze)平台搭建的智能体脂数据管理助手，支持体脂秤截图自动识别、批量录入、趋势分析与个性化健康建议，实现减脂全过程的数字化追踪。

## ⭐ 核心亮点

- 智能识别: 上传体脂秤截图，AI自动识别11项身体数据，支持一次多张批量导入
- 趋势可视化: 自动生成7天/30天变化曲线，体重/BMI/脂肪率/骨骼肌等一目了然
- 科学评估: 基于医学健康标准自动判断减脂效果，综合评分+异常预警
- 个性化建议: 根据用户年龄、性别、数据变化趋势，智能生成饮食/训练/生活习惯方案
- 卡片式交互: 简洁美观的卡片展示，类小程序体验，女生友好设计

## 🛠️ 技术栈

- AI图像识别: 豆包大模型节点 / 多模态图片理解能力
- 数据处理: 代码节点（数据解析 / 去重 / 格式化 / Excel写入）
- 趋势分析: 大模型节点（医学标准比对 / 变化趋势判断 / 综合评分）
- 数据存储: 扣子文件系统（Excel持久化存储 / 历史数据管理）
- 可视化: EChart技能（7天/30天曲线图 / 雷达图）
- 交互体验: 扣子Bot对话 / 卡片式消息推送 / 指令快捷入口

## 📐 工作流架构

```
开始节点(用户上传截图/指令) → 大模型节点(图片识别提取数据) → 代码节点(数据清洗+写入Excel) → 大模型节点(趋势分析+健康评估) → 结束节点(卡片式结果展示)
```

**核心流程：**
- 图片识别: 豆包多模态模型识别体脂秤截图，提取11项指标（BMI/脂肪率/骨骼肌量/内脏脂肪/腰臀比/基础代谢/水分率/骨盐量/蛋白质/去脂体重/身体年龄）
- 数据入库: JavaScript代码节点解析识别结果，按日期去重，写入Excel持久化存储
- 趋势分析: 大模型对比历史数据，判断减脂是否有效、肌肉是否流失，计算综合健康评分
- 结果展示: 卡片式分模块输出——录入确认卡 / 变化趋势卡 / 健康评分卡 / 建议方案卡

**快捷指令：**
- 上传截图 → 自动识别并录入
- "看趋势" → 生成7天/30天曲线图
- "看报告" → 生成完整分析报告
- "看历史" → 展示最近10条记录
- "改数据" → 手动修正识别错误

## 🚀 搭建方式

1. 登录扣子平台，创建智能体，配置人设为体脂管理助手
2. 配置系统提示词：定义识别规则、健康标准、评分逻辑、建议生成策略
3. 添加技能：加载EChart技能实现趋势可视化
4. 配置文件系统：创建Excel存储模板，设定数据写入逻辑
5. 发布到目标渠道：扣子Bot / 飞书 / 微信

## 🔧 扩展方向

- 多用户支持: 支持家庭成员各自独立记录和分析
- 智能提醒: 定时提醒称重，连续未记录自动提醒
- 饮食打卡: 接入饮食记录，关联饮食与体脂数据变化
- 周报/月报: 自动生成阶段性健康报告，定时推送
- 目标管理: 设定减脂目标，自动追踪完成进度
- 运动关联: 对接运动数据，分析训练与体脂变化的关联性
