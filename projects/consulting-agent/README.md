# 🤖 科技日报咨询智能体

> 作品集层级：**C. 工程自动化**（完整度高于同主题的 `news-feed` 工作流卡片）。

## 🚀 项目简介

基于扣子(Coze)平台搭建的每日科技资讯智能体，采用 Agent 模式整合新闻搜索与飞书消息推送，内置定时触发器，部署后无需手动干预，每日北京时间 7:30 自动推送 AI + 自动驾驶行业日报到飞书群。

## ⭐ 核心亮点

- **全自动运行**: 内置 APScheduler 定时调度器，部署即运行，每日 7:30 准时推送，无需手动开启工作流
- **Agent 自主决策**: 基于 LangGraph Agent 模式，大模型自主决策调用搜索工具、组装消息、推送飞书
- **双领域覆盖**: 同时覆盖 AI 人工智能和自动驾驶两大前沿领域，每类精选 3 条关键资讯
- **一消息到底**: 合并为一条完整消息推送，格式清晰美观，阅读体验好
- **手动触发支持**: 除定时任务外，支持飞书群内随时 @机器人 手动触发新闻推送

## 🛠️ 技术栈

- **Agent 框架**: LangGraph Agent (create_agent) + 豆包大模型 (doubao-seed-2-0-pro)
- **定时调度**: APScheduler (BackgroundScheduler + CronTrigger)
- **消息推送**: 飞书 Webhook + 文本/富文本/卡片三种消息类型
- **新闻搜索**: Coze SearchClient 网络搜索
- **运行时**: Python 3.12 + FastAPI + Coze 平台

## 📐 工作流架构

```
应用启动 → initialize() 启动定时调度器
                │
                ▼
     APScheduler (每日 7:30 触发)
                │
                ▼
     daily_news_job() ──→ execute_daily_news_push()
                │
     ┌──────────┼──────────┐
     ▼          ▼          ▼
 search_ai   search_auto  (搜索)
  _news()     _driving_news()
     │          │
     └──────────┼──────────┘
                ▼
     send_daily_news() ──→ 飞书群消息推送
```

**核心流程：**
- **定时触发**: APScheduler CronTrigger 设定北京时间每日 7:30，misfire_grace_time 1 小时容错
- **新闻搜索**: 分别调用 `search_ai_news`（AI 大模型关键词）和 `search_autonomous_driving_news`（自动驾驶 L3/L4 关键词）各获取 3 条
- **消息组装**: `_build_daily_news_message()` 按模板拼接为包含日期、分类标题、新闻详情、来源链接的完整消息
- **飞书推送**: 通过飞书 Webhook 发送文本消息到目标群

**交互方式：**
- 定时自动推送：每日 7:30 无需任何操作，自动推送
- 飞书群 @机器人：用户主动提问时，Agent 调用工具搜索并回复
- HTTP API：支持 `/run`、`/stream_run` 接口供外部系统调用

## 🚀 搭建方式

1. 登录扣子平台，创建 Agent 项目，选择 Python 3.12 运行时
2. 配置 `config/agent_llm_config.json`：设定模型（doubao-seed-2-0-pro）、系统提示词、工具列表
3. 配置飞书集成：在扣子平台添加飞书消息集成，获取 webhook URL
4. 部署运行：扣子平台一键部署，启动后调度器自动开始工作
5. 可选：通过 `/run` HTTP 接口手动触发推送，或通过飞书群 @机器人交互

## 🔧 扩展方向

- 多群推送: 支持同时推送到多个飞书群
- 个性化订阅: 用户可选择关注的领域（仅 AI / 仅自动驾驶 / 全部）
- 推送时间自定义: 支持用户自定义推送时间
- 历史归档: 推送内容自动归档存储，支持回顾查询
- 关键词过滤: 支持按公司/技术方向过滤新闻

## 🆚 与 news-feed 工作流的区别

| 维度 | 咨询智能体 (本项目) | news-feed 工作流 |
| :--- | :--- | :--- |
| 运行模式 | **Agent 自主决策** | Workflow 固定流程 |
| 定时触发 | **内置 APScheduler，自动运行** | 需外部触发或手动启动 |
| 架构 | create_agent, LLM 决策调用工具 | StateGraph 多节点 DAG |
| 交互性 | 支持对话式交互 | 仅流程执行 |
| 适用场景 | 定时推送 + 按需问答 | 一次性批量处理 |
