# 📰 科技行业资讯推送工作流

## 🚀 项目简介

解决行业资讯碎片化痛点，基于扣子(Coze)平台实现 AI/自动驾驶行业资讯的自动抓取、AI 摘要与定时推送。

## ⭐ 核心亮点

- 全自动化: 定时触发器驱动，自动抓取+AI摘要+推送，零人工干预
- 低代码搭建: 可视化工作流编排，拖拽式节点配置，无需复杂编程
- 智能摘要: 豆包大模型自动提炼关键信息，200字精华速览
- 可配置: 支持自定义推送时间、资讯来源、关键词过滤规则
- 多渠道推送: 支持扣子Bot对话、飞书机器人、微信等多端触达

## 🛠️ 技术栈

- 自动化工作流: 扣子定时触发器 / Cron表达式调度
- AI 内容处理: 豆包大模型节点 / 系统提示词工程
- 数据采集: 联网搜索插件 / 今日热榜插件 / RSSHub插件
- 数据处理: 代码节点（XPath解析 / JSON清洗 / 去重过滤）
- 工作流编排: 循环节点（批量处理）+ 选择器节点（条件分支）
- 推送渠道: 扣子Bot对话 / 飞书机器人 / 微信 / API

## 📐 工作流架构

```
开始节点(定时触发) → 联网搜索/新闻插件(采集) → 代码节点(清洗去重) → 循环节点(批量处理) → 大模型节点(AI摘要) → 结束节点(推送)
```

**节点职责：**
- 开始节点: Cron表达式触发（如 `0 20 * * 1` 每周一20:00），定义输入参数
- 新闻插件: 调用今日热榜/RSSHub/联网搜索插件，抓取目标来源最新资讯
- 代码节点: JavaScript脚本执行XPath解析、JSON清洗、去重过滤
- 循环节点: 遍历每条资讯，批量调用大模型逐条处理
- 大模型节点: 豆包模型生成150-200字摘要 + 关键词标签
- 结束节点: 格式化结果，推送到扣子/飞书/微信

## 🚀 搭建方式

1. 登录扣子平台，创建智能体，选择工作流编排模式
2. 拖拽添加节点：开始 → 新闻插件 → 代码 → 循环 → 大模型 → 结束
3. 配置大模型系统提示词：定义摘要风格、字数、输出格式
4. 设置定时触发器：Cron表达式或预设模板（每天/每周/每月）
5. 发布到目标渠道：扣子Bot / 飞书 / 微信 / API

## 🔧 扩展方向

- 多领域覆盖: 新增芯片行业、新能源储能、具身智能等垂直领域工作流
- 趋势预测: 基于历史数据，大模型分析技术演进趋势，生成周报/月报
- 知识库沉淀: 推送内容自动存入向量知识库，支持语义检索和问答
- 个性化订阅: 支持用户输入兴趣标签，按需推送
- 多语言支持: 扩展英文资讯源，大模型翻译后推送
