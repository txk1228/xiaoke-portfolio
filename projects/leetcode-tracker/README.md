# 🧠 LeetCode Hot100 刷题打卡

## 🚀 项目简介

一个轻量级的 LeetCode Hot100 刷题进度追踪工具，纯前端实现，数据保存在浏览器本地。

## ⭐ 核心亮点

- **Hot100全覆盖**：内置 LeetCode Hot100 全部题目，无需手动录入
- **分类筛选**：按难度（Easy/Medium/Hard）、状态（已解/尝试中/未解）、算法类别（动态规划/二叉树/回溯等）筛选
- **进度可视化**：实时统计解决数量、进度条、分类完成度
- **打卡备注**：每题可记录解题思路和坑点，方便回顾
- **本地持久化**：使用 localStorage 保存数据，无需后端
- **直达LeetCode**：每题内置 LeetCode 中国站链接，一键跳转刷题

## 🛠️ 技术栈

- HTML5 / CSS3 / 原生 JavaScript
- localStorage 数据持久化
- 无框架、无依赖，单个 HTML 文件即可运行

## 🚀 使用方式

直接用浏览器打开 `index.html`，或部署到 GitHub Pages：

```bash
# 本地打开
open index.html
```
